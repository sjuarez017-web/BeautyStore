PROYECTO MAQUILLAJE - BEAUTY STORE

Archivos:
- recoleccion.html
- seleccion.html
- compra.html
- css/estilos.css
- js/script.js

Uso:
1. Abre la carpeta en Visual Studio Code.
2. Abre recoleccion.html con Live Server (recomendado) o en el navegador.
3. Crea una cuenta de prueba.
4. Agrega productos desde seleccion.html.
5. Abre el carrito y realiza una compra de demostración.

Incluye:
- Bootstrap 5 responsive.
- Carrito con localStorage.
- Búsqueda y filtros por categoría.
- Animación al agregar.
- Resumen y total dinámicos.
- Validación básica.
- Servicio RESTful de demostración con GET a DummyJSON.
- CVV nunca se almacena.
- No realiza pagos reales.
